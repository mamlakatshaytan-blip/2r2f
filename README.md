# suhaib - زیکر ژمێر

ئەم بەرنامەیە گۆڕانکاریت تێدا کراوە بۆ ئەوەی **تەنها وەک یەک فایل** کار بکات. ئێستا زۆر ئاسانترە بۆ ناو AIDE یان کردنەوەی ڕاستەوخۆ.

## ڕێگەی کارپێکردن لە ناو موبایل:

١. لە ناو تێرموکس ئەم فەرمانانە بنووسە:
```bash
# بچۆ ناو فۆڵدەری پڕۆژەکەت
cd ~/wrya

# بونیادنانی پڕۆژەکە
npm run build

# کۆپی کردنی فایلی index.html بۆ ناو فۆڵدەری ١٢٣
# تێبینی: ئێستا تەنها ئەم فایلە گرنگە، چونکە هەموو شتێکی تێدایە
cp dist/index.html ~/storage/shared/123/
```

٢. ئێستا لە موبایلەکەتدا بچۆ ناو فۆڵدەری `123` و پەنجە بنێ بە `index.html`. 
- **بە بێ لۆکاڵ هۆست** کار دەکات.
- **لە ناو AIDE** بە بێ کێشە کار دەکات.

## بۆچی پێشتر شاشەکە سپی بوو؟
چونکە برۆسەرەکان ڕێگە نادەن فایلەکان بەیەکەوە ببەسترێنەوە کاتێک ڕاستەوخۆ لە ناو میمۆری موبایلەکەوە دەکرێنەوە. من ئێستا هەموو بەرنامەکەم خستۆتە ناو **یەک فایل** بۆ ئەوەی ئەو کێشەیە چارەسەر بێت.
